## Stack

React 18 · TypeScript · Tailwind CSS · Framer Motion · Vite · Vercel

Type is set in Inter Tight, Instrument Serif and JetBrains Mono. Light and dark themes follow the system setting and can be toggled.

## Editing content

All copy (projects, experience, skills, education, links) lives in [`src/content.ts`](src/content.ts).
Project screenshots are in `public/work/` as WebP; the resume is `public/Rahul_Bandikolla_Resume.pdf`.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5000
npm test         # render tests
npm run build    # production build in dist/
```
